# MVP Phase 3 — REEL・ラインテンション・魚スタミナ・釣り上げ

## 範囲・操作

ユーザー指示に基づき、Phase 2のHIT後自動リセットをファイト開始に置き換えます。`feature/mvp-fishing`だけで開発し、mainへの統合とMVP全体のAcceptanceは行いません。

CAST → !でタップ → HIT! → 右下の**REELを長押し**。LINE TENSIONが黄色・赤、またはRUNになったら**指を離す**。安全域に戻ったら再び長押しします。スタミナを削り、魚が近づくと自動で水面へ引き上げ、**CATCH!・魚名・サイズ**を表示します。約1.5秒後に釣果表示を閉じ、再びCASTできます。PCでも左クリックの長押し・解除で同じ操作です。

## 状態・責務

FishingControllerの状態はREADY（IDLE相当）、CASTING、SINKING、WAITING、BITTEN（アタリ／HOOK_WINDOW相当）、HOOKED、FIGHTING、LANDING、LANDED、FAILED、RESET。

- HOOKED: HIT!を0.3秒だけ表示し、FIGHTINGへ。Phase 2の約1秒後リセットは撤去。
- FIGHTING: REELとファイトHUDを表示。CASTと再フックを拒否。
- LANDING: 0.45秒で魚を水面へ移動し、0.2秒のしぶきを見せてから釣果へ。REELを拒否。
- LANDED: 魚の画像、名前、cmサイズを1.5秒表示。釣り入力を拒否。
- FAILED: LINE BREAK / ESCAPEDを1.3秒表示。魚は離れ、ライン・ルアーを隠す。釣り入力を拒否。
- RESET: 0.2秒間ロックしてREADYへ。成功・失敗とも次のCASTを受け付ける。

`FishingFight`はRefCountedの小さな数値モデル。テンション、スタミナ、距離、抵抗、猶予を処理します。`FishingController`が状態遷移・入力・魚とルアーの位置・演出を担当。湖の描画にはファイト判定を追加しません。魚はスタミナ、ヒット時サイズ、描画状態を保持します。HUDは表示だけを担当します。

## テンションと魚の抵抗

| 項目 | 現在の調整 |
| --- | --- |
| テンション | 0–100。開始30。LOW: 0–20未満、SAFE: 20–70未満、HIGH: 70–90未満、BREAK RISK: 90–100 |
| 巻く | 毎秒pull_power上昇。LOWでは素早く糸を張るため32/秒の補助を追加 |
| 離す | 42/秒低下。RUN中も低下するが、魚のpull_powerに応じて少し遅くなる |
| スタミナ | REEL時のみ減少。SAFEはstamina_drain、HIGH以上は1.1倍、LOWは0.12倍。RUN中はさらに0.4倍 |
| RUN | 魚種ごとの間隔で0.5秒のWARNING。魚が小さく強く動き、HUDにRUN SOON。次にRUN / RELEASEと表示 |
| RUNの抵抗 | 巻き続けるとrun_powerを追加、距離を縮める効率は0.35倍。離すと距離が0.12/秒増え、魚が戻る |
| ラインブレイク | テンション98以上を連続0.65秒維持。100に一瞬触れても即切断せず、離して98未満に戻せば猶予をリセット |
| 低テンション逃走 | テンション8以下を連続5.5秒維持するとESCAPED。通常の短い解除では逃げない |
| 距離 | 正規化したfish_distance。初期1、0に近いほどボートに近い。0–1.15に制限 |
| ランディング | スタミナ0 **かつ** fish_distance 0.08以下。片方のみでは釣り上げない |

魚が疲れきるとRUNを終え、最後の引き寄せを容易にします。巻いているボタンは明るい押下表示を維持し、離すと戻ります。テンションは緑系から黄色・赤へ移り、SAFEの範囲と境界線を見せます。HIGH時のラインは控えめな黄褐色。竿はPhase 1の元のピクセル位置を保ち、テンションで竿先だけ少し曲げます。

## 5種の仮パラメーター

`data/fish/*-fight.tres`は今回必要な名前・サイズ・スタミナ・抵抗だけの仮Resourceです。Phase 4の売値・経済・正式な魚データ体系は含めません。見た目は既存の3種類を流用し、フナは丸い魚、ナマズは長い魚、ビワマスは小魚の仮画像を使います。

| 魚 | スタミナ | pull_power | サイズcm | RUN間隔/継続 | 目標ファイト |
| --- | --- | --- | --- | --- | --- |
| ブルーギル | 20 | 8 | 10–25 | 3.5秒 / 0.65秒 | 2–4秒 |
| フナ | 30 | 10 | 15–35 | 2.8秒 / 0.65秒 | 3–5秒 |
| ブラックバス | 40 | 13 | 25–55 | 1.9秒 / 0.75秒 | 4–7秒 |
| ビワマス | 50 | 14 | 30–60 | 2.1秒 / 0.75秒 | 5–8秒 |
| ナマズ | 60 | 16 | 35–80 | 2秒 / 0.85秒 | 6–10秒 |

`size_cm`はヒット時に範囲内で0.1cm単位に決定し、同じ魚の失敗・再ヒットでは値を維持。釣果の`last_catch`へ名前・species_id・サイズをコピーします。売値や金額は計算しません。MVPの連続テストでは釣果後に同じノードを元の水中位置へ戻し、新しい仮の魚として補充します。釣果履歴やインベントリ、セーブは追加しません。

## 入力・スマートフォン

REELは基本152×72論理px。320px幅の縮小PCプレビューでも高さ44物理px以上を維持。HUDとボタンは中央16:9枠と端末Safe Areaの内側で分離します。ファイト中は深度パネルとCASTを隠し、水面へ寄る魚を覆わないようにします。通常の釣り中はPhase 2のHUDへ戻します。

押下した指のindex、またはマウスを1つだけ所有者として保持。別の指やタッチ由来のマウスイベントで解除・再押下しません。指を離す位置は問わず、ドラッグでボタン外へ出る場合も解除。アプリのフォーカス喪失で巻きを止め、押しっぱなし状態を残しません。

ハプティクスはAndroid/iOSのみ。通常REELは無振動。BITE 60ms、RUN 55ms、危険域進入35ms、LINE BREAK 130ms、ESCAPED 60ms、CATCH 100ms。Godotの非対応端末では何もしません。実機で強さ・対応状況を確認する必要があります。
